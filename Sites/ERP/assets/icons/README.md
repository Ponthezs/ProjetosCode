# assets/icons

Espaço reservado para ícones próprios do sistema (SVGs individuais),
caso no futuro seja necessário deixar de depender do Font Awesome via CDN
para algum ícone específico — por exemplo, para funcionar totalmente
offline ou para um ícone que a biblioteca não tenha.

Hoje todos os ícones do Fluxen ERP vêm do Font Awesome (carregado via CDN
em cada página); esta pasta fica vazia até que isso mude.
