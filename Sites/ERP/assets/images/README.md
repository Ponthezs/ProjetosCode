# assets/images

Espaço reservado para imagens gerais do sistema (banners, capturas de tela
usadas em documentação, ilustrações, imagens de fundo etc.).

Nesta versão o Fluxen ERP não depende de nenhuma imagem local além da
logo (veja `assets/logo`): os ícones vêm do Font Awesome via CDN e não há
banners ou ilustrações em uso. Esta pasta existe para já ter um lugar
certo quando esse tipo de arquivo for necessário, em vez de espalhar
imagens pela raiz do projeto.
