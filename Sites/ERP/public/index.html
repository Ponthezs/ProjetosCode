Arquitetura

Pronto para crescer junto com sua empresa

Hoje o Fluxen ERP funciona inteiramente no seu navegador, para você testar cada módulo sem depender de um servidor. A lógica de negócio já fica separada do armazenamento, então a evolução para uma API própria e um banco de dados de verdade acontece sem reescrever as telas.

  • Camada de serviços isolada por módulo (vendas, estoque, financeiro...)
  • Modelo de dados já desenhado para banco relacional
  • Seus dados ficam no seu navegador nesta versão de demonstração
// camada de armazenamento — troca única

  create: (data) => StorageService.insert('products', data),
  // ...
};
